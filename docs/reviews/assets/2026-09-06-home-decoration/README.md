# Скриншоты C6

Автоматизированный браузерный показ локального PoC, Chromium, viewport
390×844. Это не фотографии телефона и не пользовательское исследование.
Синтетическому покупателю через реальные meal/receipt HTTP handlers засчитаны
задания на трёх разных покупочных днях: 60 XP, уровень 2. Ручного присваивания
XP и публичного endpoint для этого нет. Создание прошлого контекста для показа
не означает прохождение нескольких дней ожидания реальным пользователем.

`default.png` — исходная кухня; `preview.png` — явно обозначенный предпросмотр;
`applied.png` — подтверждённые сервером мятные обои и цель следующего уровня.
XP при применении остаются 60. PNG исходного арта комнаты не изменён,
обои отрисованы кодом отдельно от продуктов/персонажа/мебели.

Полные границы проверки — [отчёт волны](../../2026-09-06-poc-wave-2.md).
