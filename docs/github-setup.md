# Настройка репозитория на GitHub

Ниже приведён стартовый вариант, а не принятое за команду решение. Конкретные
ограничения участники подтверждают вместе; включить их можно в интерфейсе GitHub
после публикации.

Текущее размещение:
[`x5-loyalty-hackathon/x5_loyalty_system`](https://github.com/x5-loyalty-hackathon/x5_loyalty_system),
видимость — private.

## Рекомендуемый старт

1. Создать **private** repository, пока команда не проверила правила публикации
   материалов хакатона и не выбрала лицензию.
2. Добавить двух участников с ролью `Write`.
3. Включить `Issues` и при необходимости создать Project board со столбцами
   `Backlog`, `Ready`, `In progress`, `Review`, `Done`.
4. Разрешить `Squash merging` и автоматическое удаление head branches.

## Защита `main`

Проверено 06.09.2026: `main` **не защищён**. По согласованию попытались
включить 1 approval, сброс устаревших ревью, свежие `test (3.11)`,
`test (3.14)`, `mobile`, запрет force push/удаления и применение к admin.
GitHub API вернул **403**: защита недоступна приватному репозиторию на текущем
тарифе. Rulesets также недоступны. Видимость, тариф и роли не менялись.

До отдельного решения о тарифе/публикации это организационное правило из
[CONTRIBUTING](../CONTRIBUTING.md), не технически работающий запрет:
не пушить в main и не сливать PR без ревью другого участника.

Когда функция станет доступна, создать ruleset для ветки `main`:

- запретить force push и удаление ветки;
- требовать pull request перед merge;
- требовать минимум один approval;
- сбрасывать approval при новых изменениях в PR;
- после появления CI требовать прохождение его проверок.

Для недельного хакатона этого достаточно: дополнительные обязательные проверки
следует добавлять только вместе с реально работающими командами тестов.

## Доступ и публичность

Не передавайте access tokens в чате или issue. При публикации репозитория
повторно проверьте историю Git на секреты, ПДн и внутренние материалы. Лицензию
нужно выбрать отдельно после проверки условий хакатона; её отсутствие сейчас
намеренно.
