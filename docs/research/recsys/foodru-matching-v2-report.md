# Повторная проверка food.ru-матчинга: v2

Исторический отчёт для коммита `f6f4b20`. Текущий набор расширен до 1 209
рецептов и 301 соответствия; см. [новый отчёт](foodru-expansion-300-report.md).

Выполнен [план исправлений](foodru-matching-v2-plan.md). Пересобраны статические
файлы на **тех же 601 товаре и 844 рецептах**, без новых запросов к food.ru.
Исходная база сравнения — `cf140c7`, версия правил `foodru-name-v1`.
Текущая версия — `foodru-name-v2`, политика состава — `foodru-composition-v2`.

| Показатель | v1 | v2 |
|---|---:|---:|
| Принятые пары | 244 (40,6%) | 266 (44,3%) |
| Товары с кандидатами на проверку | 355 | 333 |

Из прежних 244 принятых товаров 236 сохранили статус; у 7 из них выбран другой
рецепт. Ещё 30 товаров перешли из `review` в `matched`, а 8 прежних соответствий
отозваны. Это прирост покрытия на 22 товара. Полный список —
[`changes.csv` этапа v2](https://github.com/x5-loyalty-hackathon/x5_loyalty_system/blob/f6f4b20/recsys/data/foodru/changes.csv); все 601 товар
по-прежнему присутствуют в обогащённом каталоге.

## Исправленные ошибки

| Ошибка | Поведение v2 |
|---|---|
| Кофе из группы «Для подачи» в составе круассана | Кофе исключён из предполагаемого состава, сохранён в исходном рецепте |
| Мороженое при подаче клубничного соуса | Отделено от соуса |
| Все вторичные блоки могли считаться необязательными | Тесто, начинка и соус сохраняются; смешанные группы отправляются на проверку |
| Название рецепта подтверждало отсутствующую зелень | Нужен ингредиент в составе; для макарон с сыром и зеленью найден другой рецепт |
| Чебупели сопоставлялись с «Фаршем для пельменей» | Рецепт начинки не подтверждает целое блюдо; три соответствия отозваны |
| Сметана при подаче подтверждала томатно-сметанный соус | Подача не подтверждает компонент соуса; оба SKU ленивых голубцов остаются в `review` |
| Фарш из свинины и говядины считался лишним мясом | Уточнение уже названных видов мяса допустимо |
| «Пшеничные блины» не сходились с «блинами из пшеничной муки» | Мука считается уточнением указанного компонента |
| Прилагательные и бренды мешали совпадению | Нормализованы известные бренды и формы описательных слов |
| Гарнир «со спагетти» терялся при проверке | Проверяется отдельно, макароны не удаляются как общий маркер блюда |
| Овощи подтверждались одним чёрным перцем | Для такого подтверждения нужны распознанные овощи в основном составе |
| Багет совпадал с чиабаттой | Явно разные формы отклоняются; мини-багету выбран рецепт багета |

У **66 принятых товаров** отделены продукты для подачи. В исходных рецептах
ничего не удалено. Обнаружен 21 рецепт со смешанными группами, например «Для
пюре и подачи»: их ингредиенты не копируются и не отбрасываются автоматически.
Ингредиент для приготовления сохраняется независимо от его названия — чай
для шпрот остался в составе.

Примеры исправленных ложных отказов: чебуреки со свининой и говядиной;
пшеничные блины; курица терияки с рисом и словом «нежная»; винегрет с маслом
и рецепт с оливковым маслом; брендированная лапша Asiatique.
Все 30 новых принятых пар просмотрены агентом по названиям и составам.
Это дополнительная проверка разработки, без независимой человеческой разметки.

Отозванные 8 пар: 3 SKU чебупелей с рецептом одного фарша; мясная лазанья
со смешанной группой; котлеты из грудки и шаурма из грудки без подтверждения
конкретной части курицы; грибной суп-лапша с неподтверждённым компонентом;
неоднозначный шримп-ролл. Причины и кандидаты сохранены в `review.csv`.

## Что измерено о качестве

До правки правил зафиксированы 40 пар из v1: по 20 из `matched` и `review`,
без повторения нормализованного названия, seed `20260907`. Агент оценил
совместимость названий и состава источника. У 39 пар есть оценка, у одной
(`шримп-ролл`) формат блюда неоднозначен. Разметка и обоснования —
[`evaluation_cases.json`](../../../recsys/data/foodru/evaluation_cases.json).

| Решения на 39 размеченных фиксированных парах | v1 | v2 |
|---|---:|---:|
| Подходящая пара принята | 18 | 23 |
| Неподходящая пара принята | 1 | 0 |
| Неподходящая пара отклонена | 13 | 14 |
| Подходящая пара отклонена | 7 | 2 |

**Это выборка для разработки, использованная при исправлениях, а не независимый
тест точности.** Ноль ошибочных принятий в ней не означает 100% точность 266
итоговых соответствий. Измеряется решение по конкретной паре из v1; если v2
выбрал другой рецепт, его правильность эти числа сами по себе не оценивают.
Покрытие 44,3% также не является метрикой точности.

Две подходящие пары остались отклонёнными: осетинский пирог и куриный шницель
с пюре, где состав и подача смешаны в одной группе. У шницеля дополнительно
не разрешены название гарнира и огурчики при подаче. Для товара с осетинским
пирогом найден другой принятый рецепт, поэтому отказ по исходной контрольной
паре не означает отсутствие аналога для этого товара.

## Воспроизводимость

```bash
.venv/bin/python -m recsys.offline.foodru build
.venv/bin/python -m recsys.offline.foodru_evaluate
.venv/bin/python -m pytest tests/test_foodru_offline.py \
  tests/test_recsys_ready_food_pairs.py tests/test_recsys_merge_boundaries.py
```

Машинный отчёт этапа v2 — [`quality_report.json`](https://github.com/x5-loyalty-hackathon/x5_loyalty_system/blob/f6f4b20/recsys/data/foodru/quality_report.json).
Он связывает результат с каталогом, исходным снимком рецептов, набором
контрольных пар и конкретным `matches.json` через SHA-256. После пересборки
матчинга отчёт следует запускать заново. Каталог X5 и `recipes.json` побайтно
совпадают с v1. Рейтинги и отзывы не изменились: 493 рецепта с рейтингом,
219 с комментариями, 694 комментария.

Проверки: **86 passed** в трёх указанных тестовых файлах. Два повторных запуска
`build` и `foodru_evaluate` с `PYTHONHASHSEED=123` и `987` дали побайтно те же
8 производных JSON/CSV/TXT-файлов. Сеть при пересчёте и проверках не используется.

## Оставшиеся пробелы и следующий этап

333 строки `review` объединяют нехватку подходящих рецептов, ограничения
нормализации и неоднозначность состава. **Нельзя считать, что все эти товары
не имеют подходящего рецепта на food.ru.** В `review.csv` доступны кандидаты,
отсутствующие компоненты и смешанные группы; причины могут пересекаться.

1. Разобрать 11 лучших кандидатов со смешанными группами ингредиентов:
   отделить блюдо от подачи с явной разметкой либо найти другой рецепт.
2. Проверить пары с `named_ingredient_unconfirmed` (94 лучших кандидата)
   и `missing_named_components` (280): отличить ошибку словаря от отсутствующего
   мяса, начинки или гарнира. Ослаблять правило только с позитивным и негативным
   примером, а не снижением общего порога сходства.
3. Для оставшихся пробелов собирать рецепты адресно: по нормализованному блюду
   и обязательным компонентам. Два `unmatched` — хотстеры разных магазинов;
   торговое название не объясняет состав.
4. Перед заявлением точности провести независимую разметку новой выборки:
   отдельно сохранённые, добавленные, заменённые пары и часть `review`.
   Эту выборку не использовать для подбора правил без выделения нового теста.

Состав остаётся кулинарным допущением `recipe_name_proxy`,
`manufacturer_verified=false`. Даже подходящее название не подтверждает
рецептуру, количества или КБЖУ конкретной упаковки. Результат используется
как статический mock для PoC.
