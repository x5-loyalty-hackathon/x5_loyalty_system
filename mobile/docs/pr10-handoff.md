## Как подготовить «Опытного игрока» на машине показа

После обычного запуска backend, **из корня репозитория**:

```sh
.venv/bin/python scripts/seed_demo_progress.py --base http://127.0.0.1:8000
```

Затем выбрать «Опытный игрок» в существующем demo-переключателе профиля.
Ожидаются 1000 XP / уровень 21 / 50 наград. Скрипт не запускается автоматически
при открытии игры. Обычный cook/ready demo-checkout по-прежнему работает без него.

Журнал лежит в `outputs/demo-progress/` (игнорируется Git); его нельзя удалять
между повторами на живом сервере. После перезапуска backend запустить ту же
команду: исчезнувшие серверные offers будут созданы заново. Смена адреса сервера
получает отдельный журнал; `--state-file` позволяет явно выбрать файл.
Не запускать две подготовки одного профиля одновременно.

Если профиль уже подготовлен **исходным скриптом из `d395762`**, старых offer IDs
в журнале нет. Новая версия остановится с понятным отказом, а не скроет конфликт:
для перехода нужен чистый demo-backend (обычный перезапуск стирает его временный
прогресс всех профилей). Скрипт сам ничего не сбрасывает.

Это синтетические события: они попадают в demo-счётчики сервера, но не являются
покупками реальных пользователей, результатом eval или подтверждением uplift.
Убранство после разблокировки выбирается как раньше; скрипт не экипирует предметы.

## Короткая приёмка

1. Болоньезе → выбрать товары → «К оформлению» → Кухня → «Я приготовил».
2. Томатная паста → «Купить готовое» → одна карточка → «К оформлению» → прогресс,
   без экрана готовки. Второго бонуса за тот же покупочный день нет.
3. «Овощные ужины»: томатная паста доступна, мясное готовое блюдо отсекается.
4. «Опытный игрок» после скрипта: уровень 21, все предметы доступны для выбора.
