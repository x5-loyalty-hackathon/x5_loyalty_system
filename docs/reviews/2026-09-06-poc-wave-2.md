## Объём C6

Выбор цели и применение отдельных обоев кухни по существующему серверному
уровню. Начальные альтернативы на втором уровне, далее по одной; параметры
demo, не проверенный баланс. Без новой валюты, XP за выбор, обязательного
рецепта и новых мини-игр. Уровень/право доступа не принимаются от клиента.

Параллельные участки: backend и его регрессии; frontend и защита сессий;
read-only сверка доступного evidence коллег. Основной исполнитель сводит
контракт, документацию, проверки и браузерный показ.

- `npm run typecheck`: успешно;
- `CI=1 EXPO_NO_TELEMETRY=1 EXPO_OFFLINE=1 npm run export:check -- --max-workers 2`:

- `.venv/bin/python -m pytest -o addopts='' -q --tb=short`: **544 passed,

  `recsys/offline/foodru_evaluate.py` и `tests/test_foodru_offline.py` изменялись
  параллельно другой работой; мы их не редактировали. Повторный общий прогон
  после появления этой правки: 102,69 с. Skips — прежние optional booster/fixture,
  два предупреждения Starlette/AnyIO не являются падениями;
- `git diff --check`: чисто. Никакого нового GitHub CI или публикации не было.

Независимый read-only reviewer не обнаружил backend-проблем, проверил 40 новых
тестов оформления и reward/referral-регрессии. Точные пороги 49/50/99/100/149/150
проверены unit-проекцией ledger; HTTP-сценарии проверяют реально достижимые
20/40/60 XP и отсутствие повторной награды. Concurrent apply покрыт тестом,
совместная атомарность с наградами/reset — общей блокировкой в коде.

Frontend-review нашёл **две гонки, обе исправлены и независимо перепроверены**:

1. queued GET / последующее обновление после награды могло стереть ошибку
   применения и точное действие для повтора. Автоматическая сверка сохраняет
   их, пока сервер не подтвердит желаемый результат.
2. Поздний ответ apply из закрытой панели мог закрыть заново открытую панель.
   Обработчик теперь проверяет актуальность своего экземпляра; серверный
   результат при этом не теряется.

### Автоматизированный браузерный прогон

Chromium 153 (Playwright в отдельной временной папке, не новые зависимости
продукта), локальный backend с `RECOMMENDATION_ENGINE=model`, без fallback.
Изолированный браузер без пользовательского профиля; данные синтетические.

- **390×844:** cook с докупкой по уценке → подтверждение готовки → 20 XP;
  сохранение в книгу → repeat → ready завершается по чеку без второго бонуса
  того же покупочного дня; другой профиль/место; сетевая ошибка и повтор.
- Предпросмотр закрытого варианта не применяет его; цель сохраняется после
  обновления страницы. Ошибка сохранения цели и повтор не меняют XP.
- Для показа открытия через настоящие receipt/meal API подготовлены ещё два
  **прошлых синтетических покупочных дня**. Вместе с основным сценарием — 60 XP,
  уровень 2; мятные обои применились, восстановились после reload, заменились
  на небесные без списания XP. Это не ручной set-XP, не ожидание реальных дней.
- Обе review-гонки воспроизведены и повторно пройдены настоящими браузерными
  нажатиями с задержкой/обрывом HTTP, не только provider-harness.
- **320×740:** закрытый ночной вариант доступен для предпросмотра, apply
  запрещён; панель прокручивается, закрывается. Переход к овощному профилю
  показывает его собственные 0 XP и отсутствие цели; возврат к семейному
  восстанавливает сохранённые мятные обои. Скриншоты 390×844 просмотрены,
  исходные предметы и продукты остаются на месте.
- Проверенные сценарии не дали необработанных ошибок страницы. Предупреждения
  RN Web о deprecated shadow/pointerEvents и Node module type не исправлялись
  расширением этой задачи.

## Публикация и следующий шаг

Commit/push/merge не выполнены. C1–C4 и C6 лежат в рабочем дереве поверх
пользовательского `f6f4b20`, рядом с личным research и параллельными offline
изменениями. При публикации выделить разрешённые файлы явно, не использовать
`git add .`. Незакрытые D3–D4 не являются причиной откладывать публикацию
проверенного кода, но их нельзя закрывать выдуманными результатами.

Технический этап C6 завершён. Далее: командный прогон на целевом устройстве
и видео; ответы/материалы ML и Product для C7; публикация и финальный комплект.
Локальные тестовые серверы после проверки остановлены, их синтетическое
состояние не является сохраняемым артефактом.
