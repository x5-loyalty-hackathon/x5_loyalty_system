# Безопасность PoC

Репозиторий предназначен только для хакатонного proof of concept.

- Используйте только синтетические данные.
- Не добавляйте ПДн покупателей, внутренние данные X5 и production credentials.
- Храните токены и ключи в локальных переменных окружения; `.env` игнорируется.
- Перед публикацией логов и примеров проверяйте их на наличие секретов.
- Обнаруженный секрет не обсуждайте в публичном issue: сообщите владельцу
  репозитория напрямую и отзовите credential.

Антифрод PoC не является промышленной системой защиты и не должен применяться к
реальным операциям без отдельной проверки безопасности, качества и правовых
оснований.
